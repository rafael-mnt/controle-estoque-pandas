## 💻 Sobre
Sistema de gerenciamento de estoque executado para terminal, desenvolvido em Python com integração ao PostgreSQL por meio da biblioteca psycopg. O projeto permite gerenciar categorias, produtos e fornecedores por meio de operações CRUD, com foco em organização de código e integração com banco de dados.

## ⚙️ Funcionalidades

* Gerenciamento de categorias, produtos e fornecedores.
* Exibição dos registros em tabelas no terminal para facilitar a consulta e as operações de edição e exclusão.

## 🔧 Tecnologias Utilizadas
- Python
- PostgreSQL
- psycopg

## 📝 Como Executar
1. Clone ou baixe o repositório.
2. Crie um banco PostgreSQL.
3. Abra o arquivo `schema.sql`.
4. Execute os comandos SQL no banco de dados criado.
5. Renomeie `.env.example` para `.env`.
6. Edite o arquivo `.env` informando o nome do banco, usuário, senha, host e porta.
7. Execute `main.py`.

## 💡 Aprendizados
